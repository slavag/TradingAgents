# Selective upstream integration through v0.7.1

Target: upstream `v0.7.1` (`c454491`). Fork base: `2aa1c10` (current `main` snapshot, including AMD and Discover work). This is a semantic backport ledger, not a claim that the fork is an unmodified upstream release. The old `codex/upstream-v0.6.0-integration` branch (`ee531c3`) completed its own work but is not an ancestor of current `main`.
The local upstream history has development merges named v0.4.1/v0.4.2 but no corresponding release tags; their behavior is covered by the v0.5.0 release inventory below.

Status key: **present** = verified current-fork equivalent; **adapted** = implemented at a fork boundary; **superseded** = fork architecture intentionally replaces the upstream path; **deferred** = retained as a documented gap. Source IDs refer to upstream commits or release notes at `v0.7.1`.
